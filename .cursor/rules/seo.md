# SEO ground rules — Auto škola Sale

Apply on every page and section:

1. Semantic HTML5: `header`, `nav`, `main`, `section`, `article`, `footer` — never generic `div` when a semantic equivalent exists.
2. Exactly one `h1` per page; `h2` for main sections; `h3` for subsections. Never skip levels.
3. Every `h1`/`h2` must include at least one relevant keyword phrase naturally (see project keyword list).
4. Unique `title` (50–60 chars) and meta description (140–160 chars) per locale, primary keyword near the start.
5. `hreflang` for `sr`, `en`, and `x-default` with absolute URLs, bidirectional.
6. Self-referencing canonical on every page.
7. Open Graph + Twitter Card per locale (`og:locale` sr_RS / en_US).
8. JSON-LD `DrivingSchool` / `LocalBusiness` with real NAP data; `FAQPage` on FAQ.
9. Sitemap + robots allowing public pages; include hreflang alternates.
10. Every image needs descriptive `alt` via i18n messages (sr + en).
11. Descriptive CTA/anchor text — never “click here”.
12. Core Web Vitals: lazy images below fold, `font-display: swap`, reserved aspect-ratio for placeholders.
13. Mobile-first.
14. Clean locale URL slugs with hyphens (`/sr/...`, `/en/...`).
15. NAP consistency: name “Auto škola Sale”, address “Rudarska bb, Kostolac”, phone “+381 63 826 8876” identical in footer, contact, impressum, and schema.

Never invent prices, years of experience, instructor bios, or photos — use placeholders/TODOs until the owner confirms.
